# MERN Student App

Simple MERN application to manage students.

## Description
This project is a full-stack MERN app (MongoDB, Express, React, Node).  
It allows adding students, choosing their section, adding grades, calculating the average, and displaying student information.

## Features
- Add student  
- Update student  
- Delete student  
- Calculate average  

## Tech Stack
- React  
- Node.js  
- Express  
- MongoDB
